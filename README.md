Цель проекта собрать набор системно-административных компонентов: Bash-скрипт автоматизации, контейнеризацию Docker, RAID1 и LVM, а также HTTP-сервис за Nginx с TLS и управлением через systemd.
Публичный репозиторий: https://github.com/ogrisivrog/my-sysadmin-scripts
Состав репозитория: script.sh, Dockerfile, docker-compose.yml, README.md, sample_output.txt, .gitignore; конфигурации nginx/my-app и systemd/my-app.service добавлены отдельно.
